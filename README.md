# Projeect Name -- FitLog

FitLog is a workout library and lightweight daily training planner. Browse exercises, review their details, and build a focused plan for today's training session.

## Key Features of the Project

- See a library of workouts with muscle groups, equipment, duration, calories, and ratings.
- View workout details, including difficulty, sets, reps, and exercise instructions.
- Add up to five workouts to today's plan.
- Save workouts for later in a separate list.
- Manage today's plan and saved workouts, and mark plan items as done.
- Sort workouts by duration, calories, or rating.
- See plan totals for exercise count, minutes, and calories.
- Get toast notifications when workouts are added, saved, or removed.
- Keep plan and saved-workout data in browser local storage.

## Technologies used here to build this project

- Next.js App Router
- React 19 and TypeScript
- Tailwind CSS 4 and DaisyUI
- Font Awesome icons
- React Toastify
- Workout data from the FitLog API
